## 🚀 三步快速启动

### 1️⃣ 安装依赖

```bash
cd api
pip install -r requirements.txt
```

### 2️⃣ 启动服务

**方式一：直接运行**
```bash
python main.py
```

**方式二：使用uvicorn**
```bash
uvicorn main:app --reload
```

**方式三：使用启动脚本**
- Windows: 双击 `start.bat`
- Linux/Mac: `chmod +x start.sh && ./start.sh`

### 3️⃣ 测试API

**打开浏览器访问文档：**
- http://localhost:8000/docs （Swagger UI）
- http://localhost:8000/redoc （ReDoc文档）

**或者运行测试脚本：**
```bash
python quick_test.py
```

## 📝 快速使用示例

### Python代码示例

```python
import requests

BASE_URL = "http://localhost:8000"

# 创建PID控制器
response = requests.post(f"{BASE_URL}/pid/create", json={
    "controller_id": "my_pid",
    "Kp": 1.0,
    "Ki": 0.1,
    "Kd": 0.05,
    "setpoint": 100.0
})

print(response.json())
# 输出:
# {
#   "data": {"controller_id": "my_pid", "Kp": 1.0, ...},
#   "code": 200,
#   "message": "PID控制器创建成功"
# }

# 计算输出
response = requests.post(f"{BASE_URL}/pid/compute", json={
    "controller_id": "my_pid",
    "input_value": 75.0
})

result = response.json()
if result["code"] == 200:
    output = result["data"]["output"]
    print(f"PID输出: {output}")
```

### cURL命令示例

```bash
# 创建控制器
curl -X POST "http://localhost:8000/pid/create" \
  -H "Content-Type: application/json" \
  -d '{"controller_id":"test","Kp":1.0,"setpoint":100}'

# 计算输出
curl -X POST "http://localhost:8000/pid/compute" \
  -H "Content-Type: application/json" \
  -d '{"controller_id":"test","input_value":80}'
```

## 🎯 主要API接口

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/pid/create` | 创建PID控制器 |
| POST | `/pid/compute` | 计算PID输出 |
| POST | `/pid/setpoint` | 设置目标值 |
| POST | `/pid/tunings` | 设置PID参数 |
| POST | `/pid/reset` | 重置控制器 |
| GET | `/pid/info/{id}` | 获取控制器信息 |
| GET | `/pid/list` | 列出所有控制器 |
| DELETE | `/pid/delete/{id}` | 删除控制器 |

## 📊 统一响应格式

所有接口返回格式：

```json
{
  "data": {},           // 数据内容
  "code": 200,          // 状态码
  "message": "success"  // 消息
}
```

**状态码说明：**
- `200`: 成功
- `400`: 参数错误
- `404`: 资源不存在
- `500`: 服务器错误

## 🔥 应用场景

### 1. 温度控制
```python
# 创建温度控制器
controller_id = "temp_ctrl"
requests.post(f"{BASE_URL}/pid/create", json={
    "controller_id": controller_id,
    "Kp": 2.0,
    "Ki": 0.5,
    "Kd": 0.1,
    "setpoint": 75.0,  # 目标温度75度
    "output_limits": [0, 100]
})

# 控制循环
current_temp = 25.0
while True:
    response = requests.post(f"{BASE_URL}/pid/compute", json={
        "controller_id": controller_id,
        "input_value": current_temp
    })
    output = response.json()["data"]["output"]
    # 根据output调整加热功率
```

### 2. 速度控制
```python
# 创建速度控制器
requests.post(f"{BASE_URL}/pid/create", json={
    "controller_id": "speed_ctrl",
    "Kp": 1.5,
    "Ki": 0.2,
    "Kd": 0.05,
    "setpoint": 1500.0,  # 目标转速1500 RPM
    "output_limits": [-100, 100]
})
```

### 3. 压力控制
```python
# 创建压力控制器
requests.post(f"{BASE_URL}/pid/create", json={
    "controller_id": "pressure_ctrl",
    "Kp": 0.8,
    "Ki": 0.3,
    "Kd": 0.02,
    "setpoint": 2.5,  # 目标压力2.5 bar
    "output_rate_limits": [-10, 10]  # 变化率限制
})
```

## 💡 特性说明

### ✅ 支持的功能
- ✓ 创建多个独立的PID控制器实例
- ✓ 实时计算PID输出
- ✓ 输出限制（output_limits）
- ✓ 输出变化率限制（output_rate_limits）
- ✓ 自动/手动模式切换
- ✓ 基于测量值的比例/微分项
- ✓ 控制器参数在线调整
- ✓ 查看P、I、D各分量
- ✓ 统一的错误处理

### ⚠️ 注意事项
1. 控制器实例存储在内存中，服务重启后会丢失
2. 每个控制器需要唯一的`controller_id`
3. 生产环境建议使用Redis等持久化存储
4. 高频调用时注意设置合适的`sample_time`

## 🐛 问题排查

### 端口被占用
修改启动端口：
```python
# 在main.py最后一行修改
uvicorn.run(app, host="0.0.0.0", port=8080)  # 改为8080
```

### 依赖安装失败
使用国内镜像：
```bash
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

### 无法连接API
检查防火墙设置，确保8000端口可访问
