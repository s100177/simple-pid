# 死区功能修复方案

## ⚠️ 发现的问题

**死区功能实现错误**：当前实现判断的是误差（error）而非输出变化量（output change）。

---

## 问题对比

### ❌ 当前错误实现

**位置**：`simple_pid/pid.py` 第164-168行

```python
# Apply dead zone (死区)
# 当误差小于死区时，不调整输出
if self.dead_zone > 0 and abs(error) < self.dead_zone:
    # 误差小于死区，不调整，保持上一次输出
    output = self._last_output if self._last_output is not None else output
```

**问题**：判断 `abs(error) < self.dead_zone`，即判断**误差**是否小于死区。

### ✅ 正确实现

```python
# Apply dead zone (死区)
# 当输出变化量小于死区时，不调整输出
if self.dead_zone > 0 and self._last_output is not None:
    output_change = abs(output - self._last_output)
    if output_change < self.dead_zone:
        # 输出变化量小于死区，不调整，保持上一次输出
        output = self._last_output
```

**修复**：判断 `abs(output - self._last_output) < self.dead_zone`，即判断**输出变化量**是否小于死区。

## 错误的后果

### 场景示例

假设：
- 目标水位：61.643米
- 当前水位：61.623米
- 误差（error）：61.643 - 61.623 = **0.02米**
- 上次输出：1.0米
- PID计算输出：1.5米（需要增加0.5米）
- 死区设置：0.05米

#### 当前错误行为

```
判断：abs(error) = 0.02 < 0.05  ✓ 进入死区
结果：不调整，输出 = 1.0米（保持上次输出）
问题：虽然需要调整0.5米，但因为误差小就不调整了！
```

#### 正确行为

```
判断：abs(1.5 - 1.0) = 0.5 > 0.05  ✗ 不进入死区
结果：调整，输出 = 1.5米（或经过速率限制后的值）
符合：只有调整量<0.05米时才不调整
```

## 实际影响

### 1. 控制逻辑失效

| 情况 | 误差 | 应调整量 | 当前行为 | 正确行为 |
|------|------|---------|---------|---------|
| A | 0.02米 | 0.5米 | ❌ 不调整（误差小） | ✅ 调整0.5米 |
| B | 0.1米 | 0.02米 | ✅ 调整0.02米 | ❌ 不调整（变化小） |
| C | 0.1米 | 0.5米 | ✅ 调整0.5米 | ✅ 调整0.5米 |

可以看到，**情况A和B的行为都是错误的**！

### 2. 系统性能下降

- **情况A**：需要大幅调整但因误差小而不调整 → 响应缓慢
- **情况B**：不需要大幅调整但因误差大而频繁调整 → 频繁振荡

### 3. 与设计文档不符

文档明确说明："**调整量** < 0.05米时不调整"，但实现判断的是误差。

## 完整的修复文件

**位置**：`simple_pid/pid.py`

**完整的 `__call__` 方法修复部分**（第102-176行）：

```python
def __call__(self, input_, dt=None):
    """
    Update the PID controller.
    """
    if not self.auto_mode:
        return self._last_output

    now = self.time_fn()
    if dt is None:
        dt = now - self._last_time if (now - self._last_time) else 1e-16
    elif dt <= 0:
        raise ValueError('dt has negative value {}, must be positive'.format(dt))

    if self.sample_time is not None and dt < self.sample_time and self._last_output is not None:
        # Only update every sample_time seconds
        return self._last_output

    # Compute error terms
    error = self.setpoint - input_
    d_input = input_ - (self._last_input if (self._last_input is not None) else input_)
    d_error = error - (self._last_error if (self._last_error is not None) else error)

    # Check if must map the error
    if self.error_map is not None:
        error = self.error_map(error)

    # Compute the proportional term
    if not self.proportional_on_measurement:
        # Regular proportional-on-error, simply set the proportional term
        self._proportional = self.Kp * error
    else:
        # Add the proportional error on measurement to error_sum
        self._proportional -= self.Kp * d_input

    # Compute integral and derivative terms
    self._integral += self.Ki * error * dt
    self._integral = _clamp(self._integral, self.output_limits)  # Avoid integral windup

    if self.differential_on_measurement:
        self._derivative = -self.Kd * d_input / dt
    else:
        self._derivative = self.Kd * d_error / dt

    # Compute final output
    output = self._proportional + self._integral + self._derivative
    output = _clamp(output, self.output_limits)

    # Apply rate limits (变幅约束)
    if self._last_output is not None:
        output = self._apply_rate_limits(output, self._last_output, dt)
    elif self._integral != 0:
        # 第一次调用时，如果积分项不为0（设置了starting_output），
        # 则将输出限制在积分项附近，避免突变
        output = self._apply_rate_limits(output, self._integral, dt)

    # Apply dead zone (死区) - 修复后的版本
    # 当输出变化量小于死区时，不调整输出
    if self.dead_zone > 0 and self._last_output is not None:
        output_change = abs(output - self._last_output)
        if output_change < self.dead_zone:
            # 输出变化量小于死区，不调整，保持上一次输出
            output = self._last_output

    # Keep track of state
    self._last_output = output
    self._last_input = input_
    self._last_error = error
    self._last_time = now

    return output
```
