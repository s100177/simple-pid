# 闸门控制闸前水位 - PID API示例

本示例演示如何通过HTTP API调用PID控制器服务来实现**闸门自动控制闸前水位**。

## 应用场景

水库/河道闸门自动控制系统，根据闸前水位自动调节闸门开度，使水位维持在目标值附近。

## 控制原理

### 系统示意图

```
                    上游来水 (Q_in)
                         |
                         v
    +--------------------+--------------------+
    |                                         |
    |              闸前水域                    |
    |                                         |
    |    水位传感器 -----> 当前水位 (input)    |
    |         |                               |
    |         v                               |
    |   +------------+                        |
    |   | PID控制器  |  目标水位 (setpoint)   |
    |   +------------+                        |
    |         |                               |
    |         v                               |
    |   闸门开度 (output)                     |
    |         |                               |
    +=========|===============================+
              |
              v  闸门
         =====|=====
              |
              v
         下游出水 (Q_out)
```

### 控制逻辑（重要：方向相反！）

⚠️ **闸门水位控制与温度控制的方向相反**：

| 场景 | 温度控制 | 水位控制 |
|------|----------|----------|
| 误差为正 (目标 > 实际) | 增加加热 → 温度上升 | **减小**开度 → 水位上升 |
| 误差为负 (目标 < 实际) | 减少加热 → 温度下降 | **增大**开度 → 水位下降 |
| Kp符号 | 正 | **负** |

因此，闸门控制需要使用**负的PID参数**！

```
水位高于目标 → 误差负 → PID输出增加开度 → 加快泄水 → 水位下降
水位低于目标 → 误差正 → PID输出减小开度 → 减缓泄水 → 水位上升
```

## API调用流程

### 1. 创建控制器（注意负参数）

```json
POST /pid/create
{
    "controller_id": "gate_controller_001",
    "Kp": -20.0,      // 负值！水位每低于目标1米，开度减少20%
    "Ki": -0.5,       // 负值！
    "Kd": -5.0,       // 负值！
    "setpoint": 5.0,  // 目标水位5米
    "output_limits": [0, 100],  // 闸门开度0-100%
    "starting_output": 50.0     // 初始开度50%
}
```

### 2. 控制循环

```python
while True:
    # 读取当前水位（从传感器）
    current_level = read_water_level_sensor()
    
    # 调用API计算闸门开度
    response = requests.post(f"{API_URL}/pid/compute", json={
        "controller_id": "gate_controller_001",
        "input_value": current_level,  # 当前水位
        "dt": 1.0  # 时间步长（秒）
    })
    
    result = response.json()
    gate_opening = result["data"]["output"]  # 获取闸门开度
    
    # 控制闸门（发送指令到执行机构）
    set_gate_opening(gate_opening)
    
    time.sleep(1)  # 等待下一个控制周期
```

## 输入输出说明

### `/pid/compute` 接口

| 方向 | 参数 | 含义 | 示例 |
|------|------|------|------|
| **输入** | `input_value` | 当前闸前水位 (米) | 5.3 |
| **输入** | `dt` | 时间步长 (秒) | 1.0 |
| **输出** | `output` | 闸门开度 (%) | 45.5 |
| **输出** | `components.proportional` | P分量 | -6.0 |
| **输出** | `components.integral` | I分量 | -2.5 |
| **输出** | `components.derivative` | D分量 | 0.5 |

### 计算示例

```
当前水位: 5.3m
目标水位: 5.0m
误差: 5.0 - 5.3 = -0.3m (水位偏高)

P = Kp × error = -20 × (-0.3) = +6  (增加开度)
I = (累积项)
D = (微分项)

output = 50 + 6 + I + D ≈ 56%  (开度增加，加快泄水)
```

## PID参数调节建议

| 参数 | 建议范围 | 作用 |
|------|----------|------|
| Kp | -10 ~ -50 | 主要响应，值越大响应越快 |
| Ki | -0.1 ~ -2 | 消除稳态误差 |
| Kd | -1 ~ -20 | 抑制水位振荡 |

### 调参技巧

1. **响应太慢**：增大 |Kp|（如 -20 → -30）
2. **振荡严重**：减小 |Kp|，增大 |Kd|
3. **稳态有偏差**：增大 |Ki|
4. **洪水时反应不及**：增大 |Kp| 和 |Kd|

## 模拟场景

本示例模拟以下场景：

1. **0-100秒**：系统稳定运行，水位维持在5米
2. **100-200秒**：发生洪水，来水流量增加到2倍
3. **200-300秒**：洪水结束，观察系统恢复

## 与实际系统对接

实际应用中，需要替换模拟器为真实设备接口：

```python
# 替换水位读取
def read_water_level_sensor():
    # 从PLC/传感器读取实际水位
    return plc.read_register(WATER_LEVEL_ADDR)

# 替换闸门控制
def set_gate_opening(opening):
    # 发送开度指令到闸门执行机构
    plc.write_register(GATE_OPENING_ADDR, opening)
```

## 注意事项

1. **安全限制**：实际系统需要设置闸门开度变化速率限制
2. **故障处理**：需要处理传感器故障、通信中断等异常
3. **手动/自动切换**：需要支持手动接管控制
4. **报警机制**：水位超限时需要报警
