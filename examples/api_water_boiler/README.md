# PID控制器API调用示例 - 水温控制

本示例演示如何通过HTTP API调用远程PID控制器服务来实现温度控制。

## API服务地址

- **文档地址**: http://58.87.80.234:40002/docs
- **健康检查**: http://58.87.80.234:40002/health

## 核心概念

### PID控制器是什么？

PID控制器是工业控制中最常用的反馈控制器，通过计算**误差**（目标值与当前值的差异）来调整输出，使系统达到并维持目标状态。

```
PID输出 = P(比例) + I(积分) + D(微分)
```

### 控制流程图

```
    ┌───────────────────────────────────────────────────────────────────┐
    │                          控制闭环                                  │
    │                                                                   │
    │   目标值(setpoint)      误差(error)                               │
    │        100°C    ────┐                                             │
    │                     │   error = setpoint - input                  │
    │                     ├── = 100 - 25 = 75°C                         │
    │                     │                                             │
    │   测量值(input)     │   ┌──────────────────┐                      │
    │        25°C   ──────┘   │   PID控制器      │                      │
    │         ↑               │                  │                      │
    │         │               │  output = P+I+D │ ──→ 输出(output)     │
    │         │               │       = 85      │      加热功率=85     │
    │         │               └──────────────────┘          │          │
    │         │                                              │          │
    │         │              ┌──────────────────┐            │          │
    │         └───────────── │    热水器        │ ←──────────┘          │
    │                        │  (被控制对象)    │                       │
    │                        └──────────────────┘                       │
    │                                                                   │
    └───────────────────────────────────────────────────────────────────┘
```

## API接口详解

### 1. 创建控制器 `POST /pid/create`

创建一个新的PID控制器实例。

#### 输入参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `controller_id` | string | ✓ | 控制器唯一标识ID，用于后续所有操作 |
| `Kp` | float | | 比例增益，默认1.0 |
| `Ki` | float | | 积分增益，默认0.0 |
| `Kd` | float | | 微分增益，默认0.0 |
| `setpoint` | float | | 目标设定值，默认0 |
| `output_limits` | [min, max] | | 输出限制范围 |
| `sample_time` | float | | 采样时间（秒），默认0.01 |
| `auto_mode` | bool | | 自动模式，默认true |

#### PID参数含义

```
┌─────────────────────────────────────────────────────────────────────────┐
│  Kp（比例增益）- Proportional                                           │
│  ───────────────────────────────────────────────────────────────────────│
│  作用: 根据当前误差大小产生即时响应                                      │
│  公式: P = Kp × error                                                   │
│  特点:                                                                  │
│    • Kp越大，响应越快                                                   │
│    • Kp过大会导致振荡和不稳定                                           │
│    • 单独使用P控制会有稳态误差                                          │
│  举例: error=10°C, Kp=5 → P=50                                         │
├─────────────────────────────────────────────────────────────────────────┤
│  Ki（积分增益）- Integral                                               │
│  ───────────────────────────────────────────────────────────────────────│
│  作用: 累积历史误差，消除稳态偏差                                        │
│  公式: I = Ki × Σ(error × dt)                                          │
│  特点:                                                                  │
│    • 随时间积累，能消除持续性小误差                                      │
│    • Ki过大会导致超调和振荡                                             │
│    • 帮助系统精确达到目标值                                             │
│  举例: 累积误差=1000°C·s, Ki=0.01 → I=10                               │
├─────────────────────────────────────────────────────────────────────────┤
│  Kd（微分增益）- Derivative                                             │
│  ───────────────────────────────────────────────────────────────────────│
│  作用: 预测误差变化趋势，提前做出调整                                    │
│  公式: D = Kd × d(error)/dt                                            │
│  特点:                                                                  │
│    • 抑制快速变化，减少超调                                             │
│    • 对噪声敏感，通常基于测量值而非误差计算                              │
│    • 提供"阻尼"效果，使系统更稳定                                       │
│  举例: 误差变化率=5°C/s, Kd=0.1 → D=0.5                                │
└─────────────────────────────────────────────────────────────────────────┘
```

#### 请求示例

```json
{
    "controller_id": "water_heater_001",
    "Kp": 5.0,
    "Ki": 0.01,
    "Kd": 0.1,
    "setpoint": 100.0,
    "output_limits": [0, 100]
}
```

#### 响应示例

```json
{
    "data": {
        "controller_id": "water_heater_001",
        "Kp": 5.0,
        "Ki": 0.01,
        "Kd": 0.1,
        "setpoint": 100.0
    },
    "code": 200,
    "message": "PID控制器创建成功"
}
```

### 2. 计算控制输出 `POST /pid/compute`

**这是最核心的接口**，每次控制循环都需要调用此接口获取控制输出。

#### 输入参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `controller_id` | string | ✓ | 控制器ID |
| `input_value` | float | ✓ | **当前测量值**（如当前温度） |
| `dt` | float | | 时间步长（秒），不填则自动计算 |

#### 输入输出含义图解

```
                         输入 (input_value)
                         ──────────────────
                         含义: 传感器测量的当前值
                         例如: 当前水温 = 45.5°C
                               ↓
┌─────────────────────────────────────────────────────────────────────┐
│                         PID控制器                                    │
│                                                                     │
│   setpoint = 100°C (目标温度)                                       │
│   input = 45.5°C (当前温度)                                         │
│   error = 100 - 45.5 = 54.5°C                                       │
│                                                                     │
│   P = Kp × error = 5.0 × 54.5 = 272.5                               │
│   I = Ki × Σerror = 0.01 × 5000 = 50                                │
│   D = Kd × Δerror/Δt = 0.1 × (-5) = -0.5                            │
│                                                                     │
│   output = P + I + D = 272.5 + 50 - 0.5 = 322                       │
│   output (限制后) = min(322, 100) = 100  ← 被output_limits限制      │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
                               ↓
                         输出 (output)
                         ──────────────────
                         含义: 发送给执行器的控制量
                         例如: 加热功率 = 100 (最大功率)
```

#### 请求示例

```json
{
    "controller_id": "water_heater_001",
    "input_value": 45.5,
    "dt": 0.1
}
```

#### 响应示例

```json
{
    "data": {
        "output": 100.0,
        "input": 45.5,
        "setpoint": 100.0,
        "components": {
            "proportional": 272.5,
            "integral": 50.0,
            "derivative": -0.5
        }
    },
    "code": 200,
    "message": "计算成功"
}
```

#### 输出字段详解

| 字段 | 说明 |
|------|------|
| `output` | **最终控制输出**，直接发送给执行器（如加热器、电机等） |
| `input` | 回显的输入值 |
| `setpoint` | 当前目标设定值 |
| `components.proportional` | P分量：对当前误差的即时响应 |
| `components.integral` | I分量：累积误差的补偿 |
| `components.derivative` | D分量：对误差变化的预测调整 |

## 完整控制循环示例

```python
import requests
import time

API_URL = "http://58.87.80.234:40002"

# 1. 创建控制器
requests.post(f"{API_URL}/pid/create", json={
    "controller_id": "my_controller",
    "Kp": 5.0,
    "Ki": 0.01,
    "Kd": 0.1,
    "setpoint": 100.0,        # 目标：100°C
    "output_limits": [0, 100]  # 输出范围：0-100
})

# 2. 控制循环
current_temp = 25.0  # 初始温度
last_time = time.time()

while True:
    # 计算时间步长
    current_time = time.time()
    dt = current_time - last_time
    last_time = current_time
    
    # 调用API获取控制输出
    response = requests.post(f"{API_URL}/pid/compute", json={
        "controller_id": "my_controller",
        "input_value": current_temp,  # 输入：当前温度
        "dt": dt
    })
    
    result = response.json()
    power = result["data"]["output"]  # 输出：加热功率
    
    # 将控制输出应用到实际系统
    # (这里是模拟，实际应用中会发送给硬件)
    current_temp += power * 0.01 * dt  # 简化的温度变化模型
    
    print(f"目标: 100°C | 当前: {current_temp:.1f}°C | 功率: {power:.1f}")
    
    # 达到稳态后退出
    if abs(100 - current_temp) < 0.1:
        break
    
    time.sleep(0.1)

# 3. 清理
requests.delete(f"{API_URL}/pid/delete/my_controller")
```

## 调参建议

| 现象 | 调整方法 |
|------|----------|
| 响应太慢 | 增大Kp |
| 振荡/不稳定 | 减小Kp，增大Kd |
| 稳态有误差 | 增大Ki |
| 超调过大 | 减小Ki，增大Kd |
| 对噪声敏感 | 减小Kd |

## 典型参数参考

| 应用场景 | Kp | Ki | Kd |
|----------|-----|------|------|
| 温度控制 | 1-10 | 0.001-0.1 | 0.01-1 |
| 电机速度 | 0.1-1 | 0.01-0.5 | 0.001-0.1 |
| 位置控制 | 1-50 | 0.001-0.1 | 0.1-10 |
